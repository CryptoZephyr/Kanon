# Kanon Frontend Gate

Canonical source: [Kanon Frontend in Notion](https://app.notion.com/p/3d8c5381831281e781e7cc5c72c4c9db).

Frontend implementation is intentionally untouched. The owner must supply the Kanon product design before any visual or interaction work begins.

Until that handoff, do not choose or invent typography, layout, components, visual language, dashboard structure, animation, responsive rules, or interaction patterns. Backend and domain work may define data and API semantics only.
