# Kanon Manifest Boundary

Canonical source: [Kanon Manifest Spec in Notion](https://app.notion.com/p/3cac5381831281e09d8bc1ae6580ea2f).

The manifest is a portable declaration of what a financial-agent release needs. It is separate from company authority terms and does not grant authority.

The next phase must define stable agent identity, release identity, machine-readable capability fields, package and manifest hashes, separate company terms, canonical normalization, and the exact deterministic `permissionHash` contract. It must reject unrestricted or ambiguous financial permissions and preserve the distinction between requested capabilities and company-granted authority.

No manifest schema or hash implementation exists in this setup phase.
